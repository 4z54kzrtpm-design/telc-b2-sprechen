# TELC B2 Sprechen & Schreiben Trainer

한국어 UI의 TELC Deutsch B2 학습용 PWA입니다.

## 포함 기능

- TELC B2 Sprechen
  - Teil 1
  - Teil 2: 20개 토론 주제 랜덤
  - Teil 3: 20개 공동 계획하기 주제 랜덤
- TELC B2 Schreiben
  - 반공식 이메일 20개 과제
  - 랜덤 주제
  - 직접 작성
  - 단어 수
  - 30분 타이머
  - 모범답안
- 독일어 유용 표현
- 15분 학습 루틴
- 음성 녹음
- PWA 설치 지원
- 오프라인 캐시 지원

## GitHub Pages에 올리기

1. GitHub에 새 Repository를 만듭니다.
2. 이 폴더의 **모든 파일을 업로드**합니다.
3. 반드시 `index.html`이 Repository의 가장 바깥쪽(root)에 있어야 합니다.
4. GitHub에서:
   **Settings → Pages**
5. Source를 **Deploy from a branch**로 선택합니다.
6. Branch는 `main`, 폴더는 `/ (root)`로 선택합니다.
7. Save를 누릅니다.
8. 잠시 후 GitHub Pages 주소가 생성됩니다.

## 휴대폰에서 앱으로 설치

### iPhone / Safari
GitHub Pages 주소를 Safari로 엽니다.
공유 버튼 → **홈 화면에 추가**를 선택합니다.

### Android / Chrome
GitHub Pages 주소를 Chrome으로 엽니다.
메뉴 → **홈 화면에 추가** 또는 **앱 설치**를 선택합니다.

## 업데이트할 때

새 버전의 `index.html`을 GitHub Repository의 기존 `index.html`과 교체하면 됩니다.

서비스 워커 캐시 때문에 이전 버전이 보일 경우:
- 브라우저를 완전히 종료 후 다시 열기
- 또는 GitHub Pages 주소를 다시 로드
- 그래도 이전 버전이면 휴대폰에서 홈 화면 앱을 삭제하고 다시 설치
