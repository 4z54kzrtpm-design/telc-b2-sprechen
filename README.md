# German Exam Trainer — 휴대폰 앱 버전

포함 기능:
- TELC B1 / B2 Speaking
- Goethe B1 / B2 Speaking
- TELC B1 / B2 Schreiben
- 타이머
- 마이크 녹음 및 재생
- 학습 완료 기록(LocalStorage)
- Useful phrases
- 15-minute routine
- PWA 설치 및 오프라인 캐시

## 휴대폰에서 앱처럼 사용하기

가장 쉬운 방법은 GitHub Pages에 이 폴더의 파일을 올리는 것입니다.

1. GitHub 저장소의 기존 `index.html`을 이 `index.html`로 교체합니다.
2. 같은 폴더에 `manifest.webmanifest`, `sw.js`, `icon.svg`도 업로드합니다.
3. GitHub Pages 주소를 휴대폰 Safari/Chrome으로 엽니다.
4. iPhone Safari: 공유 → 홈 화면에 추가
5. Android Chrome: 메뉴 → 홈 화면에 추가 / 앱 설치

주의:
- 마이크 녹음은 HTTPS 환경(GitHub Pages 등)에서 정상적으로 사용할 수 있습니다.
- 서비스워커 때문에 업데이트 후 이전 화면이 보일 경우 브라우저를 완전히 닫았다가 다시 열거나 사이트 데이터를 새로고침하세요.
