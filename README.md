# telc B2 Sprechen Trainer

Mobile-first German speaking practice app for telc B2.

## Files
- `index.html` — app
- `manifest.webmanifest` — PWA installation metadata
- `sw.js` — basic offline cache
- `icon-192.png`, `icon-512.png` — app icons

## GitHub Pages
Use **Settings → Pages → Deploy from a branch → main → / (root)**.

The app is static and does not require a server.

## Important
Microphone recording and browser speech recognition require browser permission and work best on HTTPS pages such as GitHub Pages. No API key is included in this project.
